# اپلیکیشن کالانو — پروژه جدید

این پروژه یک اپلیکیشن بومی اندروید (Java) با کمترین وابستگی است. صفحه اصلی، اسلایدر بنرهای وردپرس و محصولات ووکامرس را دریافت می‌کند. با لمس محصول، صفحه محصول در مرورگر باز می‌شود. پرداخت و ورود هنوز بومی نیستند.

## ساخت APK آنلاین
1. در GitHub یک مخزن **جدید و خصوصی** بسازید.
2. **محتویات** این پوشه را در ریشه مخزن بارگذاری کنید؛ پوشه `.github` مخفی است، نمایش فایل‌های مخفی را در ویندوز روشن کنید. روش مطمئن‌تر: GitHub Desktop و Publish repository.
3. از Actions > Build Kalano APK > Run workflow اجرا کنید.
4. بعد از تیک سبز، از بخش Artifacts فایل Kalano-debug-APK را دانلود و از ZIP استخراج کنید.

## نیازمندی‌ها
Gradle 8.9، JDK 17، Android SDK API 35 و Build Tools 35.0.0. GitHub Actions این ابزارها را در سرور نصب می‌کند و به SDK کامپیوتر نیاز ندارد.

## آدرس‌های سایت
- بنرها: https://kalano.shop/wp-json/kalano/v1/banners
- محصولات: https://kalano.shop/wp-json/wc/store/v1/products?per_page=20
- دسته‌بندی‌ها: https://kalano.shop/wp-json/wc/store/v1/products/categories

اگر سایت یا افزونه API را محدود کند، اطلاعات لود نمی‌شوند. هیچ کلید مدیریتی ووکامرس در برنامه قرار ندهید.

## محدودیت
ساخت پروژه در این محیط کامپایل/روی گوشی آزمایش نشده است. اگر Actions خطا داد، متن مرحله قرمز را بفرستید. این نسخه اولیه است، نه نسخه نهایی آماده انتشار در گوگل‌پلی.
